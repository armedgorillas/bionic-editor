# Heimberg et al. (2024) Case Study Overview

## Project Background
This visualization suite implements the benchmark comparison from Figure 3 of:
> **Heimberg et al. (2024)**. *"A cell atlas foundation model for scalable search of similar human cells."* Nature 638, 1085–1094.

## Key Figures
- **Figure 3b**: UMAP of 3,000 kidney cells colored by expert author annotations.
- **Figure 3c**: The identical cells projected and colored by SCimilarity foundation model predictions.
- **Figure 3d**: Concordance heatmap matrix cross-tabulating predicted cell types versus author annotations.
